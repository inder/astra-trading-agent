# Support-box strategy v0.1 (watch-only): build brief

You are building a new Astra strategy from this brief alone. Everything you need is here or in the repository. Read
`AGENTS.md`, `README.md` (strategy sections) and `docs/decisions/0001-candle-closes-from-observed-trades.md` first.

## Branch and base

- Work on **`feat/support-box`**. It is stacked on `feat/orb-cancel-stop` (PR #32, strategy 0.10.0), which is stacked
  on `feat/orb-rules` (PR #31). Both are open, reviewed, unmerged. You need their code: the rules module, the settings
  table and the candle builder. Do not modify their behavior; if you must touch shared code, say so in your PR.
- Open your PR against `feat/orb-cancel-stop`. **Do not merge anything.** The founder merges.

## What the founder wants (his words, 2026-10-05)

> "Capture in that consolidation range … a low risk entry to take on a sizeable position. It is a very tight
> consolidation with a small range, where volatility shrinks and the market decides in favor of the bulls vs bears after
> a short period of intense deliberation." Support "can be anything: breakout level, moving average, session VWAP from
> 24/48/72 hrs." "All my strategies are only for runaway stocks."

### The reference example: SOXL, Monday 2026-10-05 (2-minute candles)

- Context: a runaway stock. SOXL closed 101.13 on Sep 14 and 164.27 on Oct 5 (+62%); the daily broke out above prior
  resistance on Oct 1–2 (Oct 1 high 156.71; Oct 2 opened 165.39, low 162.40).
- Support at 9:46: the prior breakout level (Oct 1 high, 156.71) and the VWAP anchored at the Oct 1 open (157.55).
- **The box:** 9:46–10:10, 158.08–160.22. Height 2.14 = 1.34% = **0.18 × ATR(14)** (ATR 11.57, mean true range of the
  14 sessions before the day). Average 2-minute candle range: 1.28 before the box, 1.15 in its first half, **0.86 in its
  second half (−33%)**. Its floor was a double bottom (158.15 at 9:46, 158.08 at 10:00).
- **The decision:** first 2-minute close above the box at 10:14 (160.71). Day high 164.38, close 164.27.
- Excluded examples (the founder: "bad examples", not runaway stocks): **RKT** and **IBM** on 2026-10-05. Both were
  below their 10/20/50-day averages with every anchored VWAP above the price. The runaway gate must reject them.

These numbers came from Yahoo minute bars. **Never commit market data to this public repository** (founder rule; real
bars live in a private fixtures folder, see `src/replay.ts` `--fixtures`). Tests use invented bars shaped like the
example; real-bar checks run from a private folder passed by flag or env var.

## Decisions (founder, 2026-10-05)

1. **Shares**, not options. Size = dollars at risk ÷ distance from entry to stop.
2. **Runaway stocks only**, for every strategy. A gate in front of the setup.
3. **The pattern is a tight, contracting box at support**, not "a double bottom".
4. **A separate strategy**, not an extension of the opening-range one (different instrument, sizing, timing, universe
   and holding). It shares the rules module, settings table, candle builder, levels engine, replay and journal.
5. **Roll out watch-only first (v0.1).** It detects and journals setups. **No positions, no simulated fills, no orders.**
   v0.2 (paper shares) and live come later and are out of scope.

## v0.1 scope

**Strategy id:** `support-box`, version `0.1.0`, registered beside `opening-range-options` in `src/agent-strategies.ts`.

**Rules** (new functions in `src/orb-rules.ts` or a sibling `src/box-rules.ts`, each returning `{fired, reason,
evidence}` like the existing rules; every number a row in a settings table, the way `SETTINGS` in `src/orb-options.ts`
works, generated into the MCP schema):

| Rule | Draft definition | Settings (placeholder defaults; the founder tunes them) |
|---|---|---|
| Runaway gate (daily bars before the day) | Price above a rising 10-day AND 21-day average; within X% of the 3-month high; a daily close above a prior resistance zone within the last N sessions | rising = above its value 5 sessions ago; X = 10%; N = 10 |
| Supports | (a) "broken resistance" zones from the levels engine (`src/levels.ts` marks a former ceiling now under the price), (b) 10- and 21-day averages, (c) VWAPs anchored at the open 1, 2 and 3 sessions back (typical price × volume over minute bars, regular session) | each type on/off |
| Box | A window of 2-minute candles, on the grid from 9:32 (as in 0.10.0), whose high − low ≤ H × ATR(14), lasting ≥ D minutes, whose low is within S × ATR above a support (or within it) | H = 0.25, D = 10 min, S = 0.5 |
| Contraction | Mean candle range in the box's second half ÷ mean range of the K candles before the box ≤ C | K = 5, C = 0.7 |
| Decision | First 2-minute close outside the box: up = bulls, down = bears | — |
| Levels journaled | Entry A = box low + 25% of its height (inside the box); entry B = the up-decision close; stop = box low; shares for both entries = risk ÷ (entry − stop) | risk $500 |

Candle closes follow ADR 0001: built from observed trades with `observeCandles`; an unobserved close is never acted on.

**Watch-only runtime:** a paper run of `support-box` that polls quotes like `src/orb-paper-runtime.ts`, keeps candles
per symbol, and journals events. **No positions, no budget, no fills:**
- `universe_checked`: each symbol's runaway verdict with its evidence, once before 9:32 (daily bars, as the ATR context
  prefetch does).
- `supports`: each symbol's support levels for the day, before 9:32 (VWAPs need minute bars with volume for the last 3
  sessions: Robinhood minute reads work in windows up to 5 days; 30-day requests fail).
- `box_formed`, `box_decided` (up or down) with the box, support, contraction, entries A/B, stop and shares.

**MCP read tool:** `get_support_setups` (read-only): today's boxes for a run, live and decided, with the evidence.
Update the setup guide only where it lists strategies.

## Slices (each one: design review before code, code review after; see "Process")

1. **Detector offline**: the rule functions plus a pure `scanDay(bars, dailyBars, settings)` over minute bars.
   Acceptance: on invented bars shaped like SOXL 2026-10-05 it finds one box at the right times and prices, contraction
   under the limit, decision up at the right candle; invented RKT/IBM-shaped dailies fail the runaway gate. Plus the
   same check against real bars from a private folder (skipped with a clear message when the folder is absent; never
   committed).
2. **Watch-only live run** (`support-box` strategy, runtime, journal events, replay harness support so the replay can
   run it on a past day).
3. **`get_support_setups` MCP tool**, setup-guide line, README section, version bump of the package only if the
   founder asks.

## Constraints

- Paper only. Never submit orders; this version holds no positions at all.
- No market data or account data in the repository.
- Every number is a setting with a validated range and the founder's default (founder rule: constants are config).
- Reuse; don't fork: the candle builder, settings-table pattern, levels engine, replay harness.
- `npm run check` must pass (tsc + tests); `npm run test:e2e` if any browser surface changes.

## Process

- **Before code:** an independent design review (a fresh subagent) of your plan for the slice: "what's the easy miss,
  is this the wrong thing to build". Fix what it finds before writing code.
- **After each slice:** an independent code review of the diff. Fix 🔴 and 🟡 findings; record deferrals.
- **On the PR:** a comment titled "review outcomes" listing each review's verdict, what it caught and the fixing
  commit; in the PR body, the decisions and the rejected alternatives; `Refs: #31, #32`.
- Test assertions on detector output: write each invariant in plain English first; include near-miss examples that
  must be rejected (a box slightly too tall, no contraction, a box below support, a non-runaway stock).

## Out of scope for v0.1
