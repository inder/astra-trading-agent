## Before you write code: this is the third change to the same retry logic

The today's-bars read/retry path (`#drain`, `#fetchToday`, `#recover` in `src/box-paper-runtime.ts`) has now had a
defect in each round:
1. round 1: a third attempt was cancelled early and degraded the VWAP for the day (fixed);
2. round 2: recovery after degradation was unreachable, though the PR said it was fixed;
3. round 3 (this): the in-flight cap counts attempts for reads it never sends.
The shared failure class: **state changes (attempt counts, degraded flags) are not tied to the event they describe** (a
read actually launched, a read actually succeeded or failed). Fix it at that level: write down, before code, each
piece of state and the one event allowed to change it, then make the code match that list. Add a test per row.
